# Retail Performance & Customer Retention Dashboard — Tableau Public Web Authoring Guide

This guide is tailored for **Tableau Public Web Authoring** (`https://public.tableau.com` → **My Profile → Create a Viz**) using the pre-aggregated exports generated by [`src/export_tableau_data.py`](../../src/export_tableau_data.py) (gross purchases only, `is_return = 0`, matching `sql/features.sql`).

---

## 1. Data Sources to Upload in Tableau Public Web Authoring

Upload these three files from your computer directly in the browser (all well under Tableau Public's 1 GB / 15M-row limits):

| Order | File | Contents | Used For |
|---:|:---|:---|:---|
| 1 | [`outputs/tableau/sales_performance.xlsx`](sales_performance.xlsx) | 3 sheets: `calendar_country` (`541` rows), `sales_orders` (`36,594` rows), `sales_products` (`117,282` rows) | **Dashboard 1** (all sheets in one data source — no Data Blending needed) |
| 2 | [`outputs/decile_table.csv`](../decile_table.csv) | `10` rows (Decile 1 = highest risk) | **Dashboard 2, Sheet 2A** (Churn Rate by Risk Decile) |
| 3 | [`outputs/tableau/scored_customers.csv`](scored_customers.csv) | `2,775` rows (Sept 9, 2011 test snapshot) | **Dashboard 2, Sheets 2B & 2C** (RFM Segments & Top 50 At-Risk Table) |

*(Standalone CSV versions [`sales_orders.csv`](sales_orders.csv) and [`sales_products.csv`](sales_products.csv) are also in this folder, but uploading `sales_performance.xlsx` is strongly recommended for browser Web Authoring because all three Sales sheets connect cleanly inside one data source.)*

### Step-by-Step Upload & Relationship Setup (`public.tableau.com`)
1. Sign in to [Tableau Public](https://public.tableau.com/) → **My Profile → Create a Viz**.
2. Under **Connect to Data → Files → Upload from Computer**, select **`outputs/tableau/sales_performance.xlsx`**.
3. On the **Data Source** canvas:
   - Drag **`calendar_country`** onto the canvas first.
   - Drag **`sales_orders`** next to `calendar_country` → click the connecting noodle line → match **`month_country_key` = `month_country_key`**.
   - Drag **`sales_products`** next to `calendar_country` → click the connecting noodle line → match **`month_country_key` = `month_country_key`**.
   - *(Using `calendar_country` as a 1-to-Many parent dimension prevents many-to-many inflation and lets Date Range and Country filters control every sheet in Dashboard 1.)*
   - Check field types in the grid below: ensure `order_month` and `order_date` have the **Date** icon, and `customer_id` is **String** (dimension).
4. Click **Sheet 1** at the bottom to open the worksheet editor, then add your two Dashboard 2 sources:
   - Click **Data → New Data Source → Files → Upload from Computer** → upload **`outputs/decile_table.csv`**.
   - Click **Data → New Data Source → Files → Upload from Computer** → upload **`outputs/tableau/scored_customers.csv`**.

## 2. Consistent Colour Palette (3–4 Colours Only)

Use the same palette across both dashboards:
- **Primary Navy (`#1F5A9E`)**: 2011 trend line, Top Countries/Products bars, Champions/Low-Risk segments
- **Muted Slate (`#6B7280`)**: 2010 comparison line, below-average deciles, reference lines
- **Alert Coral (`#D95F43`)**: Above-average risk deciles (`1–6`), High-risk / At-Risk segments, Dec 2011 partial-month marker
- **Light Neutral (`#F3F4F6` / `#E5E7EB`)**: subtle gridlines and KPI card backgrounds

## 3. Dashboard 1: Sales Performance (Data Source: `sales_performance.xlsx`)

> **Important:** Whenever you use `order_month`, `year`, `month_num`, `month_name`, `month_status`, or `country` on Dashboard 1, pick them from **`calendar_country`** so shared filters propagate cleanly to both `sales_orders` and `sales_products`.

### Sheet 1A — KPI Tiles
Create four calculated fields on `sales_orders`:
- `Total Revenue`: `SUM([order_value])` → format `£#,##0` (**£17,068,568** overall)
- `Number of Orders`: `COUNTD([invoice])` → format `#,##0` (**36,594**)
- `Active Customers`: `COUNTD([customer_id])` → format `#,##0` (**5,852**)
- `Average Order Value`: `SUM([order_value]) / COUNTD([invoice])` → format `£#,##0.00` (**£466.43**)

Build 4 compact single-number sheets (or 1 horizontal strip using `Measure Names` on Columns and `Measure Values` on Text) with clear metric titles.

### Sheet 1B — Monthly Revenue Trend: 2010 vs 2011 Overlaid
- **Filters**: Drag `calendar_country.year` to Filters → select **`2010`** and **`2011`**.
- **Columns**: `calendar_country.month_name` (Right-click pill → **Sort → By Field → `month_num` Ascending** so it displays `Jan` → `Dec`).
- **Rows**: `SUM([order_value])` (format `£#,##0,,"M"` or `£#,##0,"K"`).
- **Color**: `calendar_country.year` (as Discrete Dimension: `2010` = `#6B7280`, `2011` = `#1F5A9E`).
- **Mark Dec 2011 as partial**:
  - Drag `calendar_country.month_status` onto **Shape** (or duplicate `SUM([order_value])` as a dual axis with Circles colored by `month_status` so `Partial (Dec 1-9)` stands out in Alert Coral `#D95F43`).
  - Right-click the Dec 2011 data point → **Annotate → Mark**: `"Dec 2011 partial (Dec 1–9 only: £512K)"`.
- **Tooltip**: `Year`, `Month`, `Revenue`, `Orders (COUNTD(invoice))`, `Active Customers (COUNTD(customer_id))`, and `month_status`.

### Sheet 1C — Top 10 Countries by Revenue
- **Rows**: `calendar_country.country` → Filter **Top 10 by `SUM(order_value)`** → Sort descending by `SUM(order_value)`.
- **Columns**: `SUM([order_value])` (`#1F5A9E`), Label: `SUM([order_value])` + `% of Total`.
- **Tooltip**: `Country`, `Revenue`, `% of Total`, `Orders`, `Active Customers`.

### Sheet 1D — Top 10 Products by Revenue
- **Rows**: `sales_products.product_label` → Filter **Top 10 by `SUM(revenue)`** → Sort descending by `SUM(revenue)`.
- **Columns**: `SUM([revenue])` (`#1F5A9E`).
- **Tooltip**: `Product (description)`, `Stock Code`, `Revenue`, `Units Sold (SUM(units_sold))`, `Orders (SUM(order_count))`.

### Dashboard 1 Assembly & Cross-Sheet Filters
1. Arrange: 4 KPI tiles across the top → Sheet 1B (Monthly Trend) in the middle → Sheet 1C (Top 10 Countries) + Sheet 1D (Top 10 Products) side-by-side at the bottom.
2. Add two filters from **`calendar_country`** on the dashboard:
   - `order_month` (Continuous Month/Year **Range of Dates** slider, `Dec 2009` – `Dec 2011`)
   - `country` (**Multiple Values (Dropdown)** with Search & All)
3. On both filter cards, click the dropdown arrow → **Apply to Worksheets → All Using This Data Source**.
4. **Critical Top-10 Context Step**: Open Sheet 1C and Sheet 1D, right-click the `order_month` and `country` filter pills on the **Filters** shelf, and choose **Add to Context** (pills turn gray). This ensures Tableau applies the Date & Country filters *before* computing the Top 10 bars!

### Verified Insight Caption (Dashboard 1)
> **What the data shows:** Revenue surges in autumn across both years—September through November generate **36.2% of 2010 revenue (£2.97M)** and **37.7% of 2011 revenue (£3.08M)**, peaking in November (**£1.16M** in 2010 and **£1.14M** in 2011)—while the **United Kingdom accounts for 83.7% (£14.29M)** of total sales (*Dec 2011 includes Dec 1–9 only*).

## 4. Dashboard 2: Customer Retention (Data Sources: `decile_table.csv` & `scored_customers.csv`)

### Sheet 2A — Churn Rate by Risk Decile (Source: `decile_table.csv`)
- **Columns**: `decile` (Discrete Dimension, `1` to `10`, where `1 = Highest Risk`).
- **Rows**: `SUM([churn_rate])` (formatted `0.0%`).
- **Calculated Fields**:
  - `Overall Churn Rate`: `{ FIXED : SUM([churners]) / SUM([customers]) }` (`38.5%`)
  - `Risk vs Average`:
    ```text
    IF [churn_rate] > { FIXED : SUM([churners]) / SUM([customers]) }
    THEN "Above Average Risk"
    ELSE "Below Average Risk"
    END
    ```
- **Color**: Put `Risk vs Average` on **Color** (`Above Average Risk` = `#D95F43` for Deciles 1–6; `Below Average Risk` = `#6B7280` for Deciles 7–10).
- **Reference Line (Web Authoring)**:
  1. Drag `Overall Churn Rate` onto **Detail** on the Marks card.
  2. In the left sidebar, switch from the **Data** tab to the **Analytics** tab.
  3. Drag **Reference Line** onto the **Table** drop zone.
  4. Set Value = `Overall Churn Rate` (**Average**), Line = dashed `#6B7280`, Label = Custom `"Avg Churn Rate: 38.5%"`.
- **Tooltip**: `Decile`, `Customers`, `Actual Churners`, `Churn Rate`, `Mean Predicted Risk`, `Cumulative Share of Churners`.

### Sheet 2B — Customers by RFM Segment (Source: `scored_customers.csv`)
- **Rows**: `rfm_segment` → Sort descending by `COUNTD([customer_id])` (`Champions: 576`, `Hibernating: 462`, `At Risk: 403`, `Need Attention: 340`, `Potential Loyalists: 312`, `Loyal Customers: 289`, `Can't Lose Them: 245`, `Recent Customers: 148`).
- **Columns**: `COUNTD([customer_id])`.
- **Color**: Put `AVG([predicted_risk])` on **Color** using a 2-color Navy-to-Coral diverging palette (`#1F5A9E` low risk → `#D95F43` high risk).
- **Tooltip**: `Segment`, `Customers`, `Avg Predicted Churn Risk (0.0%)`, `Actual 90d Churn Rate (AVG(churned), 0.0%)`, `Avg Total Spend (£#,##0)`, `Avg Recency (days)`.

### Sheet 2C — Top 50 Highest-Risk At-Risk Customers Table (Source: `scored_customers.csv`)
- **Filter**: `is_top50_at_risk` = `True` (keeps `risk_rank` `1`–`50`; predicted risk `90.9%`–`95.5%`).
- **Rows** (Discrete, sorted by `risk_rank` Ascending): `risk_rank`, `customer_id`, `last_order_date` (**Exact Date → Discrete**, `yyyy-mm-dd`).
- **Columns / Text**: Put `Measure Names` on **Columns**, and `Measure Values` (`predicted_risk` formatted `0.0%`, `total_spend` formatted `£#,##0.00`) on **Text**.
- **Tooltip**: Add `country`, `rfm_segment`, `n_orders`, and `recency_days` to Tooltip for quick context without crowding the table.

### Dashboard 2 Assembly
- Upper row: Sheet 2A (Churn Rate by Risk Decile) left + Sheet 2B (Customers by RFM Segment) right.
- Bottom row: Sheet 2C (Top 50 At-Risk Customers) full-width scrollable action table, with subtitle `"Sept 9, 2011 active-customer test snapshot (n = 2,775)"`.

### Verified Insight Caption (Dashboard 2)
> **What the data shows:** The top two risk deciles churn at **69.8%** and **60.6%** (vs. the **38.5%** average) and capture **33.9% of all churners**, while **865 Hibernating and At-Risk buyers** alongside **245 "Can't Lose Them"** accounts (averaging **£3,937** spend and **111 days** since last order) offer the highest-impact retention targets.
